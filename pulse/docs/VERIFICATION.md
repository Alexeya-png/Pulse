## Покрытые сценарии

**Снимки и сравнение:** первая проверка без ложных отписок; отписки и новые подписчики при повторном посещении; отсутствие повторных событий при третьей неизменившейся проверке; отдельная история; переименование по ID; одинаковое количество при изменившемся составе; снятые лайки; недоступная публикация; идемпотентность; время и порядок наблюдений; откат транзакции; разделение аккаунтов; пагинация истории.

**Невзаимные подписки:** вычисление уже на первой проверке; обновление при следующей; переименование; пустой список подписок; отсутствие пары и разные даты не считаются нулём; курсорная пагинация 175 результатов без повторов; разделение профилей.

**Сбор:** все страницы подписчиков и подписок; дубликаты; неполный список; повтор курсора; изменившиеся/скрытые счётчики; неполная пара не обновляет подписчиков; отмена; лимит запросов; ошибка сети не превращается в пустой список; усечённые лайки не вызывают ложных событий.

**Собственный HTTP-клиент:** только разрешённые адреса Instagram и GET; таймауты; отсутствие перенаправлений/автоповторов; secure-cookies; фильтрация и проверка cookies; отклонение старого формата подключения; сверка владельца сессии; неизвестный счётчик остаётся неизвестным; некорректный формат профиля останавливает обновление; ответы 429/challenge/login; HTML вместо JSON; сокрытие секретов в сообщениях сетевых ошибок; настройки сессии без пароля.

**Импорт:** повреждённые записи, дубли ключей JSON, даты без часового пояса, смешение способов идентификации, неполные наборы файлов ZIP, опасные пути, исходящие лайки вместо входящих. Импорт — программный вспомогательный интерфейс, не режим входа мобильного приложения.

## Что остаётся перед выпуском

Собрать APK и проверить на реальном Android: доступность страницы входа Instagram в WebView, вход с 2FA/подтверждением, извлечение и восстановление сессии, работу Keystore, очистку WebView, две полные проверки контролируемого аккаунта, восстановление после сети/паузы/перезапуска, системную клавиатуру и длинные списки. Текущий код не подтверждает доступность внутренних адресов Instagram для реального аккаунта.

Ни пароль, ни действующая сессия Instagram в проект не включены. Собственный HTTP-клиент не является официальным API Meta; поддержка со стороны Instagram не гарантируется.
